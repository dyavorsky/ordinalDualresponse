A realistic aggregate study: estimation, dichotomization, and tests

This vignette analyzes a realistic (but homogeneous-preference) study: two 3-level attributes plus price, four alternatives per task, a five-point purchase-likelihood follow-up, and 3,600 tasks (think 300 respondents times 12 tasks).

Simulate and estimate

library(ordinalDR)
beta <- c(a2 = 0.8, a3 = -0.5, b2 = 0.4, b3 = 1.0, price = -0.9)
cut <- c(-1.0, 0.2, 1.2, 2.2)
des <- dr_design(3600, J = 4, seed = 42)
dat <- dr_simulate(des, matrix(beta, 1, 5), cut, model = "B", seed = 43)
table(dat$y) / length(dat$y)

What dichotomizing the scale costs

Collapsing the five-point response at the top-2-box turns the data into the binary dual response of the literature. The binary model is correctly specified (collapsing a cumulative-link model at one of its own cut points is exact), so the cost is efficiency, not bias:

dat_bin <- dr_dichotomize(dat, k = 4)
fit_bin <- dr_mle(dat_bin)
round(rbind(ordinal = fit$se_beta, binary_t2b = fit_bin$se_beta), 4)
#>              [,1]   [,2]   [,3]   [,4]   [,5]
#> ordinal    0.0448 0.0531 0.0509 0.0479 0.0347
#> binary_t2b 0.0459 0.0540 0.0519 0.0490 0.0355

The Fisher machinery quantifies this exactly. The second stage contributes information weight \(\omega\) per task; dichotomization discards part of it:

mu <- log(rowSums(exp(matrix(des$X %*% beta, ncol = 4, byrow = TRUE))))
c(W5 = mean(dr_omega(mu, cut, "B")),
  top2box = mean(dr_omega(mu, cut[3], "B")),
  topbox = mean(dr_omega(mu, cut[4], "B")))
#>        W5   top2box    topbox 
#> 0.3165852 0.2315862 0.1637389

Specification tests

Two one-degree-of-freedom tests come with the model: the unit slope on the inclusive value (\(\lambda = 1\)), and the conditioning parameter that spans our model (\(\delta = 0\)) and DR-2Max (\(\delta = 1\)):

dr_spec_tests(dat, mle = fit)
#>                  test    estimate         se      wald_z          lr
#> 1          lambda = 1  1.02771053 0.07491791   0.3698786   0.1382648
#> 2           delta = 0 -0.03455182 0.04887645  -0.7069216   0.4988692
#> 3 delta = 1 (DR-2Max) -0.03455182 0.04887645 -21.1666735 339.7410178
#>         p_wald         p_lr
#> 1 7.114729e-01 7.100122e-01
#> 2 4.796152e-01 4.799974e-01
#> 3 1.937605e-99 7.265615e-76

On data generated by the model, \(\lambda = 1\) and \(\delta = 0\) are retained and DR-2Max is decisively rejected.
